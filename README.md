# Face Recognition System

## 📌 Project Overview

The Face Recognition System is a Python-based computer vision project that detects faces from an input image and compares them with a known person's face.

## 🎯 Objectives

- Detect human faces
- Generate face encodings
- Compare faces
- Identify known and unknown persons
- Display the recognition result

## 🛠️ Technologies Used

- Python
- OpenCV
- face_recognition
- NumPy
- Matplotlib
- Google Colab
